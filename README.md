## Featured Projects

### 1. Retail Intelligence & Analytics
**End-to-End Business Intelligence | Olist E-commerce**

Built an end-to-end analytics workflow across a nine-table e-commerce dataset.

- Processed a dataset containing **1.55 million rows**, 99,441 orders, and R$13.59 million in revenue.
- Executed 32 logged cleaning actions and passed all 54 post-cleaning tests following a 202-test data quality audit.
- Designed a PostgreSQL star schema with **6 dimensions and 4 fact tables**.
- Developed 15 SQL scripts for sales, customer, seller, and delivery KPIs.
- Cross-validated SQL and Pandas results across 31 numeric comparisons.
- Built a **four-page Power BI report** with DAX measures.
- Identified that the top 10 product categories generated **62.36% of revenue**.

**Tech:** PostgreSQL, SQL, Python, Pandas, NumPy, Power BI, Excel

### 2. Transaction Risk Observatory
**Fraud Analytics & Data Quality Framework**

Developed a SQL-based fraud analytics pipeline using the IEEE-CIS transaction dataset.

- Processed **590,540 transactions** and 144,233 identity records.
- Built an ELT pipeline and star schema across four schemas.
- Developed 10 explainable fraud signals and an additive risk score from 0–7.
- Identified a device-sharing segment with a **7.27% fraud rate versus a 3.50% baseline**, representing 2.08x lift.
- Created KPI views covering $79.74 million in transaction volume and $3.08 million in estimated fraud exposure.
- Automated **98 data quality checks** across nine domains.
- Reduced a segmentation KPI query from 69.9 seconds to 16.4 seconds — a **76.5% runtime reduction**.

**Tech:** PostgreSQL 18, SQL, PL/pgSQL, Python, Git
